## 带入 M6 的专项与已知边界

| 项目 | 当前证据／后续要求 |
| --- | --- |
| Sync 冲突 | 基础设置／链接与图标复验通过；离线双端编辑、活动分块送达与旧分块清理交叠未确认。发布前验证并修复数据丢失风险，不能把基础同步通过当作冲突处理通过 |
| 生命周期 | 重载、模拟升级、完整重启的数据保留通过；context unloaded 压力场景、启动立即刷新 Bing 和长期后台轮换仍需专项验证 |
| 容量／恢复故障 | 自动资源采样覆盖 32 MiB，另有用户 37.1 MB ZIP 成功迁移；更大样本与容量阈值未验收。单 store 事务不等于跨数据库／storage 全局回滚；需验证中断行为并准确说明恢复方式 |
| 浏览器／分发 | ESR、其他桌面系统、真实签名安装与升级未验收；正式发布范围须与证据一致 |
| 外部服务 | 用户 WebDAV 通过，但服务类型、协议和各错误路径没有单独记录；真实密钥图片服务、权限撤销与长期在线运行仍待验证 |

进入 M5 只表示可继续品牌和分发准备，不代表以上事项已通过，也不代表已具备发布条件。M5 完成后按 M6 清单验收，再处理正式签名与分发。
