# HTTP 取图与候选图标选择

2026-10-03。用户报告 `http://news.qq.com/`、`http://www.bilibili.com/` 图标刷新后模糊，并建议自动判断无法可靠挑选时由用户选择候选图。

## 原因与修正

在隔离 Chrome 中，旧包请求 HTTP 页面和常见图标路径均失败；普通运行包只有 HTTPS host_permissions 和 connect-src，因此原站声明没有被解析，最终使用 Google 回退。腾讯新闻回退为 96 像素 PNG，B站回退为 128 像素 JPEG。改查 HTTPS 页面后，取得腾讯新闻原站 96 像素 ICO、B站原站声明的 512 像素 PNG。ICO 和 PNG 的画布尺寸依然不能证明可见细节；尤其腾讯新闻原图仍只有 96 像素，不能据此承诺所有放大场景都高清。

公共默认端口 HTTP 链接先尝试相同路径／查询参数的 HTTPS 页面，成功时用最终地址解析声明和常见路径；失败仍尝试原地址，再走现有回退。本机／内网 IP、特殊本地域名和非默认显式端口不改取图地址。此规则不改快捷链接导航地址、不新增 HTTP 权限，也没有域名特判。

## 候选选择

- 新增或编辑链接时，自动样式下点击“选择图标”，主动获取原站声明、manifest、常见路径、浏览器缓存和两种备用服务候选。正常自动发现仍按原有优先规则取一个结果，并不会每次都请求全部备用服务。
- 列表显示当前缓存及可用候选、来源类别和实际尺寸／SVG。按原始文件 SHA-256 去重；不同编码的相同外观仍可能分别显示。网络候选最多 8 个、返回原始字节合计不超过 1 MiB，沿用每图 512 KiB 上限和超时限制。没有可用新候选时仍保留当前图标。
- 打开列表不会修改缓存，点击即应用；选择仅保存在本机缓存，同页可见 Dock／启动台和预览随之更新。关闭编辑窗口不撤销已点击的选择，修改链接内容仍需保存。
- 普通编辑保存、重载和较晚完成的自动请求不会覆盖新选择。主动刷新恢复自动选择并清除选择标记；清空缓存后需要重新选。候选请求返回后若窗口关闭、URL 或样式改变，则丢弃其界面结果并释放 Blob URL。
- 本机选择不随快捷链接账号同步；没有将 Blob URL 写成自定义图片地址。原图、来源和选择标记留在现有图标缓存，不改变数据库版本。隐私页说明主动获取候选会访问备用服务。
