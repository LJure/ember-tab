## 自动图标尺寸修复补充

真实自动发现选中网站 manifest 中的 PNG：`https://picasso-static.xiaohongshu.com/fe-platform/fbd46ec8a907ca6a8cacc9596f18ff495c639feb.png`。原图 128×129，排除微弱抗锯齿像素后主体约 108×109，边距约 10px，与截图中约 84% 的视觉占比相符；两个容器没有小红书专用缩放规则。

### Brave 备份对照与补充修复

用户反馈自动图标仍偏小，但导入 Brave 备份后正常，并确认导入前后模式都是“自动”。按用户提供的本地 ZIP 路径，只提取小红书的链接与图标缓存记录进行比较，未把备份或用户链接记录提交到仓库。

- 备份中的自动图标来自 `favicon.vemetric.com`，128×128、全画布不透明。导入会恢复该图片缓存，所以即使模式仍为自动，也不会立刻改用官网当前图片。
- Firefox 当前自动发现选中官网 manifest 的另一张图，原图 128×129。初轮裁切后的 112×112 中，alpha 大于约 50% 的主体仅 106×107，可见宽度约 94.6%；因此还有“小一圈”的现象。
- 补充修复按 alpha ≥128 的可见主体计算边界，忽略极淡边缘。整幅都较淡、没有达到该阈值的图片仍保持原样。当前小红书生成 107×107 显示图，可见宽高占比实测均为 100%。保持宽高比、缓存原图、手动图片、取图来源优先级和请求范围不变，不承诺不同来源的图案细节完全相同。
- 将合成样本增加极淡外边缘；真实图片测试同时断言可见宽高占比均 ≥98%，不再仅断言裁切后画布变小。用提取的 Brave 图片和官网图片分别走真实自动缓存显示路径，并排复核 Dock／启动台的 64px 图标框，大小基本一致。

最新验证：**85 文件／637 单测通过**；Firefox 156.0.1、ESR 140.16.0 **各 14 项图标专项通过**，均含真实小红书自动发现和缓存再次显示。ESLint 0/0，可复现构建 1 项通过，web-ext 0 错误／52 项原有警告；未重复跑不相关的大备份套件。原始证据 `.local/icon-backup-comparison/`，并排图 `comparison.png`，机器摘要见 M6_EVIDENCE.json 的 `iconSizeBackupFollowup`。随后用户反馈“验证通过”，关闭本次图标缺陷的人工复验项；其余网站尚未提供具体样本，不泛化为所有网站图案完全一致。

## 本轮修复

同步清理原来会枚举并删除所有非活动分块，包含其他设备刚送达、尚未发布活动指针的分块。现在只清理本次提交明确替换的旧代，每批删除前确认活动指针没有被切换；未确认归属的分块予以保留。配额预检使用相同清理范围，不再假定这些分块可以被删除。

另一处问题是链接列表、活动指针和内容块独立送达时，旧代码可能把暂时找不到内容的链接或文件夹子项过滤掉。现在读取快照时先检查引用完整性；不完整则保留上次完整视图，禁止基于这份快照写入，待后续数据到达再恢复。

新增 5 个回归用例在修复前全部失败，修复后全部通过，覆盖远端暂存、活动指针切换、列表先到、内容先到和缺少文件夹子项。真实 Firefox 中也验证了远端暂存和列表先到两类场景。

这不是跨设备冲突合并。Firefox Sync 按键处理冲突，本机 Web Locks 无法锁住另一设备或同步服务；完整但相互竞争的修改、同 ID 不同内容、删除与编辑冲突以及清理读取与删除之间的跨设备竞态仍需解决。引用检查无法识别所有混合代数据，未知残留分块可能占用 Sync 配额，不能盲目清空它们。按用户最新决定，双设备冲突合并移至后续版本，首版不承诺该能力。同步语义依据 [MDN storage.sync](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/storage/sync)。

## 大备份、压力与中断边界

128 MiB 样本是 16 个各 8 MiB 的二进制 Blob，OPFS 导出后恢复并逐个核对 SHA-256；不是 128 MiB 的真实照片渲染性能测试。

| 指标 | 稳定版 | ESR 140 |
| --- | --- | --- |
| ZIP 字节数 | 134,242,014 | 134,254,361 |
| 导出耗时 | 7.09 秒 | 12.22 秒 |
| 导出＋恢复＋校验 | 9.05 秒 | 16.99 秒 |
| 采样到的 Firefox 进程树工作集峰值 | 1,337,446,400 字节 | 1,162,002,432 字节 |
| 采样次数 | 12 | 20 |

工作集覆盖该测试浏览器进程树，包含浏览器基础开销；约 500ms 间隔加上采样开销，并非精确峰值或扩展独占内存。不同测试运行负载不同，不用于比较两版本性能，也不推出 500 MiB／2 GiB 阈值已经实测。

快速关闭 20 个标签页期间，每页启动 8 组后台消息和存储读取；原页面随后 20 个消息全部得到回复，本地标记保留。稳定版仍记录关页时 `JSWindowActorChild cannot send at the moment`，栈指向图库监听注册；ESR 记录关闭期间脚本加载取消。未见遗留页面或后台失效，但不声称控制台零错误或所有销毁竞态已消除。M3 的本机 HTTP 图片 CSP 拦截、M5 的 HTTP 拒绝属于已知测试诊断。

恢复中断测试在资产库导入完成、下一数据库导入前注入异常。结果正确返回失败，但图片库已恢复为备份内容，设置仍保留恢复前状态；随后用同一备份重新恢复成功。**目前没有跨数据库和 storage 的全局回滚。** 本用例证明错误可检测、受控中断后可重试，不证明断电／强杀后原状保留。用户最新决定维持现有处理，额外保护留待后续版本，不再作为首版门槛；未实现项保持未勾选。
